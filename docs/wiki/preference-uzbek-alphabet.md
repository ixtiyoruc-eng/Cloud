# User preference: Uzbek Latin letters on screen

On 2026-11-15 the user asked that on-screen Uzbek text (captions, graphics) uses these four letters, Turkish-style, and nothing else changes: sh→ş, ch→ç, o'→ö, g'→ğ (capitals Ş, Ç, Ö, Ğ). Other letters (x, q, the ʼ sign) stay as in standard Uzbek Latin.
