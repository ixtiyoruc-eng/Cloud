# Wiki conventions

On 2026-11-15 the user agreed the wiki lives in `docs/wiki/`.

- `index.md` lists every page, grouped by category, with a one-line summary.
- One page per thing: a decision, a recurring problem, a subsystem, a user preference. Link related pages.
- Date every claim. Cite `ixtiyoruc-eng/Cloud@<sha>` for claims about code.
- Never rewrite an old claim; add a new dated one and mark the old "superseded".
- Sources (issues, PRs, transcripts, subagent reports) are cited, never copied.
